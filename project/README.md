# Explore Mexico

This is a mobile app built with [Expo](https://expo.dev) and React Native.

## Tech Stack
- Expo
- React Native
- TypeScript
- Zustand
- Expo Router
- React Native Reanimated

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Make a development build

   ```bash
   npx expo prebuild
   ```

3. Run the development build

   ```bash
   npx expo run
   ```

## Project Structure
- app/        -> Screens and routes
- components/ -> Reusable UI components
- store/      -> Zustand stores
- hooks/      -> Custom hooks shared across the app
- assets/     -> Images, fonts
- features/   -> Feature-specific components and logic
- docs/       -> Project documentation
